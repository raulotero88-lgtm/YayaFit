## 📊 Especificaciones Técnicas (TL;DR)

| Parámetro | Valor | Notas |
|-----------|-------|-------|
| **Género** | Electropop / Downtempo Pop | Accesible, relajante |
| **BPM** | 100 ± 5 | 95-105 es rango verde; 105-110 aceptable; fuera es NO |
| **Duración** | 2:30 - 3:30 | Usar Extend si < 2:30 |
| **Voz** | Femenina cálida | Clara, no robótica, español correcto |
| **Idioma** | Español (España) | Para audiencia YayaFit |
| **Tema** | Libre | Respiración consciente + movimiento lento + comunidad |
| **Gancho** | "Respira y sigue / El ritmo en tu pecho / Te lleva a casa" | Debe ser muy pegadizo |
| **Instrumentos** | Synths cálidos, beat groovy, bajo melódico | Sin guitarras, sin distorsión |
| **Energía vocal** | Media | Confidencia pero sin fuerza bruta; invita a respirar |
